🔐 SEGURANÇA
════════════════════════════════════════════════════════════════════════════════

✅ Sem acesso público
   → Não existe link no menu principal
   → Sem botão "Acessar Admin" no index.html

✅ Tokens únicos e seguros
   → Cada admin recebe um token diferente
   → Tokens válidos por 7 dias

✅ Criptografia
   → Tokens armazenados com hash SHA-256
   → Senhas protegidas

✅ Sessão temporária
   → Expira após 24 horas
   → Necessário novo token para continuar

✅ URL protegida
   → Token removido da URL após acesso
   → Não fica visível no histórico de navegação

💡 DICAS IMPORTANTES
════════════════════════════════════════════════════════════════════════════════

1. Altere a senha padrão em PRODUÇÃO
   $env:ADMIN_PASSWORD = "sua-senha-forte"
   node server.js

2. Use HTTPS em produção (não apenas HTTP)

3. Compartilhe links apenas por canais seguros
   ✅ WhatsApp, Email, Telegram
   ❌ Chat público, Slack público

4. Mantenha backup de data/admin_tokens.json

5. Revise o log de tokens regularmente

6. Gere novos tokens periodicamente


🔗 ROTAS DE API
════════════════════════════════════════════════════════════════════════════════

POST /api/admin/generate-token
   Gera novo token de acesso
   Requer: { "adminPassword": "...", "email": "..." }

POST /api/admin/verify-token
   Valida um token recebido
   Requer: { "token": "..." }

GET /api/admin/stats
   Retorna estatísticas do dashboard
   
GET /api/admin/activity-log
   Retorna log de atividades recentes

GET /api/admin/featured-events
   Retorna eventos em destaque

GET /api/admin/users
   Retorna lista de usuários cadastrados

GET /api/admin/tickets
   Retorna lista de ingressos anunciados


❓ DÚVIDAS FREQUENTES
════════════════════════════════════════════════════════════════════════════════

P: Posso acessar direto em admin.html?
R: Não! Será exibido "Acesso Negado". Você PRECISA do token na URL.

P: E se perder o link?
R: Gere um novo token com: node generate-admin-token.js

P: Quanto tempo o token é válido?
R: 7 dias após geração (configurável em server.js)

P: A sessão expira?
R: Sim, após 24 horas de inatividade (configurável em admin.js)

P: Posso usar em mobile?
R: Sim! Basta compartilhar o link via WhatsApp/Email.

P: Como altero a senha admin?
R: Configure a variável ADMIN_PASSWORD antes de rodar server.js

P: Quero usar em produção, o que fazer?
R: 1) Configure ADMIN_PASSWORD
   2) Use HTTPS (não HTTP)
   3) Use um proxy (nginx, Apache)
   4) Configure PM2 para manter servidor rodando
   5) Revise segurança regularmente
